# Java OOPS Practice Programs

This repository contains my practice programs for learning and understanding Object-Oriented Programming (OOPS) concepts in Java.  
Each program focuses on a specific OOPS topic and helps strengthen core Java fundamentals.

## 📚 Topics Covered
- Classes and Objects  
- Constructors  
- Method Overloading & Overriding  
- Inheritance (Single, Multilevel, Hierarchical)  
- Abstraction  
- Interfaces  
- Polymorphism  
- Encapsulation  
- Exception Handling  
- Multithreading
  

## 🗂️ Folder Structure

🚀 How to Run

Compile and run using Java command-line tools:

javac FileName.java
java FileName
